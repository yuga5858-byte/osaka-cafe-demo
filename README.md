# 大阪カフェ 営業用デモサイト「珈琲と焼菓子 ひだまり舎」

ホームページ制作サービスの営業で、お客様（大阪の個人経営カフェ）に完成イメージを見せるためのデモです。
**店名・価格・住所・電話番号・営業時間はすべて架空**です。予約・Instagramボタンは接続しておらず、押すと「未接続」の案内が出ます。

公開URL（GitHub Pages）: https://yuga5858-byte.github.io/osaka-cafe-demo/

## ファイル構成と役割

```
osaka-cafe-demo/
├── docs/                 ← 公開されるサイト本体（GitHub Pages はこのフォルダを公開します）
│   ├── index.html        ページの中身（文章・見出し・メニュー・営業時間など）
│   ├── css/style.css     見た目（色・文字・余白・スマホ対応）
│   ├── js/main.js        動き（スマホメニュー、営業中表示、「未接続」の案内）
│   ├── images/           イラスト（すべてこのデモ用に作成したオリジナルSVG）
│   └── .nojekyll         GitHub Pages に「そのまま公開して」と伝える空ファイル（消さない）
├── tests/site.test.mjs   自動テスト（公開はされません）
└── README.md             この説明書
```

ビルド作業は不要です。HTML・CSS・JavaScript だけで動き、外部のフォント・地図・SNSなどには通信しません。

## ローカルで見る

`docs/index.html` をダブルクリックしてブラウザで開く。または：

```bash
cd docs
python3 -m http.server 8000
```

ブラウザで <http://localhost:8000> を開きます。止めるときは `Ctrl + C`。

## 修正して公開に反映する

1. `docs/` の中のファイルを修正する
2. 変更をコミットして `main` ブランチに push する
3. 1〜数分で公開URLに反映される（反映されないときはブラウザを再読み込み）

| やりたいこと | 修正する場所 |
|---|---|
| 店名・文章・メニュー・価格を変える | `docs/index.html` |
| 営業時間を変える | `docs/index.html` の表 **と** `docs/js/main.js` の `HOURS` の両方 |
| 色を変える | `docs/css/style.css` 先頭の `:root` |
| 画像を写真に差し替える | `docs/images/` に写真を置き、`index.html` の `<img src="…">` と `alt` を書き換える |

写真に差し替える場合は、**お店が撮影した写真、または利用規約で商用利用が確認できる素材だけ**を使い、出典・許諾の記録を残してください。

## 注意

- このページには `noindex`（検索エンジンに載せない設定）が入っています。営業時にURLを直接お伝えして見てもらう想定です。
- リポジトリは公開（Public）なので、ソースコードも誰でも見られます。お客様の個人情報や非公開情報は入れないでください。
- 実際のお店のサイトとして本番化する場合は、架空情報の差し替え・デモ表示の削除・`noindex` の削除・予約/Instagramの接続が必要です。

## テスト

```bash
node --test tests/site.test.mjs
```

Playwright（ブラウザ自動操作ツール）が必要です。スマホ幅・PC幅での表示崩れ、外部通信がないこと、デモ表記、アクセシビリティ、未接続ボタンの動作などを確認します。
