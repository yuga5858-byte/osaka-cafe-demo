About

ゆっくり過ごせる、
街の縁側のような場所

築八十年の長屋を、できるだけ元の梁や建具を残して改装しました。 店主がひとりで焙煎から焼菓子づくりまで担う、小さなお店です。

珈琲豆は、産地ごとの個性が出るよう少量ずつ店内で焙煎しています。 お好みの味わいを伺いながら、一杯ずつハンドドリップでお淹れします。

  • 01店内焙煎のスペシャルティ珈琲
  • 02国産小麦・発酵バターの焼菓子
  • 03全12席・Wi-Fi／電源あり
